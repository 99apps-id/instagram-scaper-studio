## ✨ Fitur Unggulan

- 📞 **Ekstraksi Nomor WhatsApp & Email Bisnis**: Mengambil nomor telepon publik dari tombol kontak profil resmi dan deteksi regex nomor WhatsApp aktif di bio.
- 📈 **Kalkulasi Engagement Rate (ER %)**: Mengkalkulasi rasio interaksi likes dan komentar dari 12 postingan terbaru terhadap total followers.
- 🔥 **Top Hashtags & Viral Topic Detection**: Menemukan tagar dan topik yang paling sering mendatangkan interaksi pada akun-akun tertarget.
- 💬 **One-Click Direct WhatsApp**: Tombol satu klik untuk langsung membuka chat WhatsApp ke prospek bisnis tanpa menyimpan nomor kontak terlebih dahulu.
- 🔒 **Login Session Aman**: Menggunakan sesi login resmi pengguna sendiri di browser lokal tanpa pernah menyimpan password di server.
- 📊 **Ekspor Excel Terformat (.xlsx)**: File laporan Excel siap pakai untuk tim sales & CRM marketing.
