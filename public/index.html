Pertanyaan Umum (FAQ)

Bagaimana cara mengaktifkan lisensi?

Buka menu Pengaturan → Lisensi, pilih paket QRIS Singapay atau masukkan kode aktivasi manual, lalu klik Aktivasi Sekarang.

Apakah saya harus menghubungkan akun Instagram?

Tidak wajib, tetapi sangat disarankan. Menghubungkan akun menghindari rate limit dan memungkinkan akses ke data lengkap (WhatsApp, Email, Engagement Rate). Klik tombol Hubungkan Akun IG di toolbar.

Berapa lama masa trial gratis?

3 hari penuh sejak aplikasi pertama kali dibuka. Setelah masa trial habis, scraping dan export Excel diblokir hingga lisensi diaktifkan.

Data saya disimpan di mana?

Semua data scraping dan sesi disimpan lokal di perangkat Anda (folder %APPDATA%/Insta Scraper Studio). Tidak ada data yang dikirim ke server eksternal.

Bagaimana cara memindahkan lisensi ke komputer lain?

Buka menu Pengaturan → Lisensi → Nonaktifkan Lisensi di komputer lama, lalu masukkan kode aktivasi yang sama di komputer baru.

Apakah aplikasi ini aman?

Ya. Aplikasi tidak mengirim data pribadi ke server mana pun. Scraping dilakukan melalui API publik Instagram. Integritas aplikasi diverifikasi saat startup.
