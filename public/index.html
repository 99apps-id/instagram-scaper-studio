FAQ — Pertanyaan Umum

Insta Scraper Studio

Berapa lama masa trial gratis?

3 hari penuh sejak aplikasi pertama kali dibuka di perangkat ini. Status hari tersisa tampil di pill lisensi bilah navigasi.

Bagaimana cara mengaktifkan lisensi?

Buka menu Pengaturan → Lisensi, pilih paket via QRIS Singapay (aplikasi aktif otomatis) atau masukkan kode aktivasi serial Anda lalu klik Aktivasi Sekarang.

Apakah saya harus menghubungkan akun Instagram?

Tidak wajib, tetapi sangat disarankan. Menghubungkan akun menghindari rate limit dan memungkinkan akses ke data kontak lengkap (WhatsApp, Email & Engagement). Sesi disimpan aman di perangkat Anda.

Saya ganti perangkat / laptop, bagaimana?

Buka menu Pengaturan → Lisensi → Nonaktifkan lisensi di perangkat ini di laptop lama, lalu masukkan nomor serial yang sama di laptop baru Anda.

Apakah data hasil scrape saya disimpan aman?

Ya. Semua data tersimpan 100% lokal di perangkat Anda (folder dataset aplikasi). Tidak ada data leads yang dikirim ke pihak luar.

Kode aktivasi saya ditolak padahal baru dibeli?

Pastikan format huruf besar semua tanpa spasi (cth: GMST-YYMM-XXXXXX). Bila ada kendala, hubungi support@99apps.id sertakan ID instalasi Anda.
